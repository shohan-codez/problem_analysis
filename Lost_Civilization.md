## My Approach
> as of black box rule, we first saw the constraints.so O(n^2) wont work . we need either nlogn approach , or O(n) approach . After working with the examples a bit , i saw that there is some kind of tree relation, then found  stack relation , so i thought of this way. the element i am working on , if it is the next element of the top element of stack , then i will put it in that stack . if its not the next element of the top element of the stack then i will check if its next to  any element of that stack . if not then this element is the new generator , and for this the length will increase or simply , i have to include this element to the final array.

## Explanation (Step 4)
> In formal way , the problem will give you an array , there are numbers that can be generated by incrementing from another number. and  you have to find the generators.
> 
> i implemented a stack approach without using stack . so i will keep a parent variable and a last variable. if current element is the next element of the last, then i will just update last as the current element. if its not the next element of the last , but its between parent and last element i will also then keep the current element as last, and if not any of them , then this is the new parent , and this is the new last. this way just keep count of the parents , and you are good to go .

## Code
```cpp
#include<bits/stdc++.h>
using namespace std;

#define ll long long 

void solve(){
  ll n;
  cin>>n;
  vector<ll>a(n);
  for(int i =0;i<n;i++)cin>>a[i];
  ll cnt = 0;
  ll parent = a[0];
  ll last= a[0];
  int i =0;
  while(i<n){
    if(a[i]-last==1){
        last= a[i];
    }
    else{
        if(parent<a[i] && a[i]<=last){
            last = a[i];
        }
        else{
            parent = a[i];
            last= a[i];
            cnt++;
        }
    }
    i++;
  }
  cout<<cnt<<endl;
}
int main(){
    int t;
    cin>>t;
    while(t--)
    solve();
}
```
