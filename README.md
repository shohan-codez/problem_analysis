# Problem Analysis Journal

A collection of my competitive programming problem analyses.

Each entry follows a structured format to build lasting mental mapping. 

## Format
Every problem analysis includes:
- **Key Insight** — the one sentence that unlocks the problem
- **Signal** — what should trigger this approach next time
- **My Approach** — how I actually solved it
- **Dead Ends** — what I tried and why it was wrong
- **Explanation** — full solution in plain words, no code
